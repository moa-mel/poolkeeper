# Poolkeeper — Instant Launch Simulator

**Poolkeeper** is an interactive strategy simulation that teaches and showcases **Loadout Instant Launch** mechanics.

You manage a game token’s bonding curve, liquidity depth, anti-snipe protection and studio allocations through five challenging rounds. Survive the market events and successfully “graduate” the token — just like a real Instant Launch on Loadout.

This project was built specifically to demonstrate Loadout’s newest self-service launch flow (Instant Launches), fee structure, graduation targets and liquidity management.

## How to Test
Click Start Instant Launch Simulation.
Allocate your energy across:
Studio Buyback / Staking Reserve
Bonding Curve Liquidity
Anti-Snipe Protection

Review the market event for the current round.
Submit your allocation and watch pool health, slippage and graduation progress update.
Survive all five rounds and reach the simulated 85 SOL graduation target.
On the results screen, use the “Launch for real on Loadout” button.

**No account, wallet connection, private key, or faucet is required.**

Everything is simulated. No real cryptocurrency or on-chain transactions are involved.
