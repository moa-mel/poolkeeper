# Poolkeeper — Instant Launch Strategy & Readiness Tool

## How to Test

**No wallet or account required.** Poolkeeper is a browser-based simulation. All market events, allocations, and outcomes are simulated; no real tokens or funds are involved.

### Live Demo

[https://poolkeeper.onrender.com](https://poolkeeper.onrender.com)

### Run Locally

```bash
git clone https://github.com/moa-mel/poolkeeper.git
cd poolkeeper
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

### Test the Game Modes

**Launch Simulator**
1. Select **Launch Simulator** from the home screen.
2. Play through five rounds, responding to market events and adjusting resource allocations.
3. Review your final score and game outcome.

**Game Economy Crisis Mode**
1. Select **Play Game Economy Crisis Mode**.
2. Adjust the allocation sliders; verify the allocation total remains at 100.
3. Select **Resolve Crisis** and observe how your decisions affect the game economy.
4. Complete five rounds and review your result.

## What Is Poolkeeper?

Poolkeeper is a strategy and readiness layer built on top of Loadout Instant Launches.

Loadout makes it possible to launch a game token in minutes. Poolkeeper helps creators make better launch decisions—with a focus on healthy graduation, liquidity depth, anti-snipe protection, and studio allocation strategy.

Poolkeeper is **not a replacement for Instant Launch**. It is an additional decision-support and optimization tool that helps creators prepare for and manage a launch.

## What Poolkeeper Adds to Instant Launch

- **Pre-Launch Readiness Score** — Assess your project before launching.
- **Strategy Coach** — Get recommendations during the bonding curve.
- **Graduation Probability Simulator** — Explore how allocation choices affect the simulated chance of graduating healthily at the 85 SOL target.
- **Anti-Snipe + Liquidity Optimizer** — Balance protection and liquidity depth under market pressure.
- **Exportable Strategy Summary** — Take recommended settings into your real Instant Launch workflow.

## Built For

Game creators using Loadout Instant Launches who want to make more informed launch decisions.
